# AIML Week 1 Assignment - Student Performance Analysis

## Project Overview

This project was completed as part of the AIML Internship Week 1 Assignment.

The objective of this project is to perform data cleaning, exploratory data analysis, visualization, and business insight generation using a student performance dataset.

## Dataset Information

Dataset Name: Student Performance Dataset

Number of Records: 708

Number of Features: 10

Features:

* Student_ID
* Gender
* Study_Hours_per_Week
* Attendance_Rate
* Past_Exam_Scores
* Parental_Education_Level
* Internet_Access_at_Home
* Extracurricular_Activities
* Final_Exam_Score
* Pass_Fail

## Libraries Used

* Pandas
* NumPy
* Matplotlib
* Seaborn

## Tasks Completed

### Task 1 - Data Cleaning and Analysis

* Dataset inspection
* Missing value analysis
* Duplicate record detection
* Data cleaning
* Descriptive statistics generation

### Task 2 - Data Visualization

* Histogram
* Count Plot
* Box Plot
* Scatter Plot
* Correlation Heatmap

### Task 3 - Business Insight Report

Generated insights and recommendations based on data analysis.

## Key Findings

* No missing values were found.
* 208 duplicate records were identified and removed.
* Study hours positively influence final exam scores.
* Attendance rate positively correlates with performance.
* Past exam scores are the strongest predictor of final exam performance.
